<h1>Drowsiness Detection &amp; Attention Monitoring</h1>

<p>A real-time drowsiness detection system using MediaPipe Face Mesh for landmark extraction, a trained Logistic Regression classifier, and an LLM advisory layer for attention monitoring feedback.</p>

<hr>

<h2>Project Overview</h2>

<p>This project processes driver-facing video from the <strong>DMD (Driver Monitoring Dataset)</strong> to extract facial landmarks, classify alertness states, and generate natural language advisories using an LLM. The pipeline runs in distinct stages: data collection, a two-step preprocessing phase, model training, and live inference.</p>

<p><strong>Classes:</strong> <code>alert</code> &middot; <code>drowsy</code> &middot; <code>microsleep</code></p>

<h2>Pipeline Architecture</h2>

<pre><code>DMD Videos (.mp4) &amp; JSON Annotations
      │
      ▼
1. Dataset Collection.ipynb &amp; label_parser.py
  └── Extracts raw x, y, z MediaPipe coordinates to CSV.
  └── Maps frame numbers to the corresponding label (microsleep &gt; drowsy &gt; alert).
      │
      ▼
2. Preprocessing Phase
  └── preprocess_step_1.ipynb: Computes Euclidean distances to extract EAR (Eye Aspect Ratio) and MAR (Mouth Aspect Ratio).
  └── preprocess_step_2.ipynb: Normalizes coordinates relative to face center, scales per-frame to [-1, 1], and drops z-coordinates.
      │
      ▼
3. Logistic Regression Model.ipynb
  └── Applies a 30-frame rolling window for EAR/MAR mean and standard deviation.
  └── Handles class balancing (SMOTE, Undersampling).
  └── Trains a multinomial Logistic Regression classifier and exports LogisticRegressionModel.joblib.
      │
      ▼
4. inference.ipynb
  └── Real-time webcam feed extraction.
  └── Computes real-time EAR/MAR and 30-frame rolling features.
  └── Feeds 962-dimensional vector to the loaded model for live HUD overlay.</code></pre>

<h2>Running the Inference Notebook</h2>

<p>To test the model in real-time using your webcam:</p>

<ol>
    <li><strong>Verify Model Path:</strong> Open <code>inference.ipynb</code>. Ensure <code>MODEL_PATH</code> points correctly to the compiled model (e.g., <code>"Models\\LogisticRegressionModel.joblib"</code>).</li>
    <li><strong>Camera Configuration:</strong> Check the <code>CAMERA_INDEX</code> variable. It defaults to <code>0</code> (built-in webcam). If you are using an external USB camera, you may need to change this to <code>1</code>.</li>
    <li><strong>Execution:</strong> Run all cells sequentially. The final cell contains the <code>main()</code> function, which will launch a dedicated OpenCV window.</li>
    <li><strong>Initialization:</strong> The HUD will display <code>"Warming up..."</code> for the first 30 frames as the system fills the rolling deque required for the time-series mean/std calculations.</li>
    <li><strong>Real-Time HUD:</strong> Once the buffer is full, the HUD will display the predicted class (<code>Alert</code>, <code>Drowsy</code>, or <code>Microsleep</code>), the prediction confidence percentage, and the live EAR/MAR values.</li>
    <li><strong>Termination:</strong> Press the <strong><code>Q</code></strong> or <strong><code>ESC</code></strong> key while focused on the OpenCV window to safely release the camera and close the application.</li>
</ol>

<h2>Label Mapping</h2>

<p>DMD annotations are parsed and mapped to three classes based on an established temporal hierarchy:</p>

<table>
    <thead>
        <tr>
            <th align="left">DMD Annotation</th>
            <th align="left">Project Label</th>
        </tr>
    </thead>
    <tbody>
        <tr>
            <td><code>eyes_state/open</code></td>
            <td><code>alert</code></td>
        </tr>
        <tr>
            <td><code>eyes_state/opening</code></td>
            <td><code>alert</code></td>
        </tr>
        <tr>
            <td><code>eyes_state/close</code></td>
            <td><code>drowsy</code></td>
        </tr>
        <tr>
            <td><code>eyes_state/closing</code></td>
            <td><code>drowsy</code></td>
        </tr>
        <tr>
            <td><code>yawning/Yawning with hand</code></td>
            <td><code>drowsy</code></td>
        </tr>
        <tr>
            <td><code>yawning/Yawning without hand</code></td>
            <td><code>drowsy</code></td>
        </tr>
        <tr>
            <td><code>microsleep</code></td>
            <td><code>microsleep</code></td>
        </tr>
    </tbody>
</table>

<p><em>Note: Normal blinks are filtered out to prevent false drowsy flags. An <code>eyes_state/close</code> lasting &gt;= 0.5s is continuously and retroactively labeled as <code>microsleep</code>.</em></p>
